📱 2. Integración en Android (Ej: com.israviolink.pulso)

En tu aplicación Android nativa, puedes abrir el portal de autorización con Chrome Custom Tabs para una experiencia fluida y recibir el código mediante un Deep Link.

Paso A: Declarar el Deep Link en AndroidManifest.xml 

<activity android:name=".OAuthCallbackActivity" android:exported="true">
    <intent-filter>
        <action android:name="android.intent.action.VIEW" />
        <category android:name="android.intent.category.DEFAULT" />
        <category android:name="android.intent.category.BROWSABLE" />
        <!-- Deep link: israviolink-pulso://oauth/callback -->
        <data android:scheme="israviolink-pulso" android:host="oauth" android:path="/callback" />
    </intent-filter>
</activity>

Paso B: Lanzar la pantalla de autorización (Kotlin) 

val authUrl = "https://proviweb-d8764-c592e.web.app/oauth-authorize.html?" +
    "client_id=com.israviolink.pulso&" +
    "redirect_uri=israviolink-pulso://oauth/callback&" +
    "scope=profile+email+qav&" +
    "state=" + UUID.randomUUID().toString()

val customTabsIntent = CustomTabsIntent.Builder().build()
customTabsIntent.launchUrl(context, Uri.parse(authUrl))

Paso C: Recibir el código e iniciar sesión 

// En OAuthCallbackActivity.kt:
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    val uri = intent?.data
    val code = uri?.getQueryParameter("code")
    val state = uri?.getQueryParameter("state")

    if (code != null) {
        // Canjear código con la Cloud Function oauthTokenExchange
        exchangeCodeForToken(code)
    }
}
