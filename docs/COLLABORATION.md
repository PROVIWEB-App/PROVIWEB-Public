# 🤝 PROVIWEB — Collaboration

## 🌎 Construyamos juntos el futuro de la música

PROVIWEB es un ecosistema digital orientado a conectar música, tecnología, educación, comunicación, servicios y nuevas oportunidades.

La colaboración de la comunidad puede ayudar a mejorar diferentes áreas del ecosistema.

# 💡 Proponer una idea

Si tienes una idea para mejorar PROVIWEB:

1. Comprueba si existe una propuesta similar.
2. Crea una Issue.
3. Explica claramente la idea.
4. Describe qué problema intenta resolver.
5. Explica cómo podría beneficiar a los usuarios.
6. Espera la revisión del equipo PROVIWEB.

Una propuesta no garantiza que la funcionalidad vaya a incorporarse.

---

# 🐛 Reportar un error

Cuando encuentres un problema, proporciona tanta información como sea posible.

Incluye:

* Descripción del problema
* Pasos para reproducirlo
* Comportamiento esperado
* Comportamiento observado
* Dispositivo
* Versión de Android
* Versión de PROVIWEB
* Capturas de pantalla cuando sean útiles

### ⚠️ Importante

No publiques información privada, credenciales, tokens, claves ni datos personales.

---

# 🔐 Problemas de seguridad

Las vulnerabilidades de seguridad **no deben publicarse mediante Issues públicos**.

Si descubres una vulnerabilidad que pueda comprometer:

* cuentas;
* datos;
* autenticación;
* infraestructura;
* comunicaciones;
* información financiera;
* información privada;

debe comunicarse mediante un canal privado establecido por PROVIWEB.

Consulta `SECURITY.md` para conocer las recomendaciones de seguridad.

# 📋 Pull Requests

Las contribuciones de código deben:

* Tener un propósito claro.
* Mantener una estructura comprensible.
* Evitar cambios innecesarios.
* No incluir secretos.
* No incluir credenciales.
* No introducir código de procedencia desconocida.
* Respetar las licencias de terceros.
* Incluir información suficiente para revisar el cambio.

Una Pull Request puede ser modificada, rechazada o cerrada después de la revisión.

---

# 🔒 Información que nunca debe publicarse

Nunca incluyas en una Issue, Pull Request o commit:

```text
google-services.json
keystores
private keys
wallet seeds
passwords
authentication tokens
API secrets
Firebase credentials
production credentials
datos personales
```

Si accidentalmente publicas información sensible, no basta con eliminar el archivo del último commit. Debe considerarse que la información pudo quedar registrada en el historial.

---

# ©️ Propiedad intelectual

La colaboración con PROVIWEB no implica automáticamente la transferencia de derechos sobre la marca, identidad visual, contenidos, código privado o demás propiedad intelectual de PROVIWEB.

Las contribuciones deberán respetar los derechos de terceros y las licencias correspondientes.

PROVIWEB se reserva el derecho de revisar y determinar qué contribuciones son apropiadas para su integración.

---

# 🚫 Uso de la identidad PROVIWEB

Las contribuciones no autorizan a terceros a:

* Presentarse como representantes oficiales de PROVIWEB.
* Utilizar la marca PROVIWEB para crear confusión sobre una versión oficial.
* Distribuir productos modificados como si fueran productos oficiales.
* Utilizar elementos de identidad de PROVIWEB de forma que implique respaldo oficial inexistente.
